C.O.R.E. workflow: This system involves four steps:
- Capture: Quickly record new tasks or ideas.
- Organize: Sort and categorize the captured information with due dates or tags.
- Review: Regularly process your organized information to schedule and act on tasks.
- Engage: Execute the work or take action on the items you have reviewed. 

The idea comes from GTD, where the mind is for capturing ideas, but not retaining them. Moving them to written format quickly is essential so that we don't overwhelm.
Using any planning tool, note down the tasks, allocate time to go through and set deadlines (or set the deadline right then and there). 
Regularly review tasks to see if they need time to be allocated and set timeblocks
